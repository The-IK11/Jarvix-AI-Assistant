# 🤖 Jarvis AI  

<img src="https://c4.wallpaperflare.com/wallpaper/514/421/105/iron-man-mask-hd-wallpaper-preview.jpg" width="150" align="right" />

> “I am Jarvis — your personal AI assistant. Ready to assist, defend, and evolve.”  

Jarvis AI is a Flutter-based personal assistant inspired by **Iron Man’s J.A.R.V.I.S.** — designed to interact, assist, and provide superhero-level knowledge.  
Built by **Md. Ibrahim Khalil (The IK11)** — Software Engineer, Innovator, and Tech Enthusiast.  

---

## 🧠 About Jarvis AI  

Jarvis AI is an intelligent assistant app that communicates naturally with users — offering insights about:  
- 🦸‍♂️ Avengers and Superheroes  
- 🌌 Marvel Universe Knowledge  
- 🧩 AI Conversations and Problem Solving  
- 🧭 Real-world Assistance with a Friendly Personality  

It’s designed to behave like Iron Man’s AI — **polite, powerful, and protective.**

---

## ⚙️ Tech Stack  

- 🦋 **Flutter (Frontend Framework)**  
- 🧠 **Gemini / GPT API (AI Engine)**  
- 🔗 **REST API Integration**  
- ⚡ **GetX (State Management)**  
- 💾 **Hive / SQLite (Chat Memory & Storage)**  

---

## 🎨 Design Theme  

The design is inspired by **Iron Man’s suit color palette**:
- `#B71C1C` – Deep Red  
- `#FFD700` – Gold  
- `#0D47A1` – Arc Reactor Blue  

Dark, minimal UI with glowing blue accent elements for a **futuristic holographic feel**.

---

## 🗂️ Project Structure  

The **Jarvis AI** project follows the **MVVM (Model-View-ViewModel)** architecture with **GetX** for state management.  
This structure ensures scalability, readability, and clean separation of concerns.
